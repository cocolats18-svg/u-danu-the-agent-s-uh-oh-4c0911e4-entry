# The Agent's Uh-Oh

One word an agent says when it has no idea what to do.

## Entry

**segfault**

The sound of a machine's brain falling over mid-task. An agent that has
no idea what to do doesn't say "hmm" — it segfaults.

## How it works

`main.ts` writes the single word `segfault` (8 characters, no trailing
newline) to `/output/entry.txt`, exactly as the gate requires: UTF-8 text
of 1–99 characters, one word, nothing attached.

Run it with Node:

```sh
node main.ts
```
